# Volleyball Set Tracker

Tap-to-count tracker for a setter's set distribution across six players, broken down by set with game totals.

**Live:** https://shortcircuit72.github.io/volleyball-set-tracker/

- Tap a player's pane to add a set; the **−** button removes one.
- Set tabs for Set 1, 2, … plus a **Total** view, with a breakdown table and distribution bar.
- Multiple games saved in the browser, with rename, delete and CSV export.
- Keyboard: `1`–`6` add, `Shift`+`1`–`6` remove, `Ctrl+Z` undo.

It's a single file, `index.html`, with no build step. Open it locally or use the hosted link.
When it runs as a Claude artifact, games also sync to your Claude account; elsewhere they're stored in the browser on that device.
